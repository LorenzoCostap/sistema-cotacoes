# Frontend — Sistema de Cotações

Interface em **React** do [Sistema de Cotações](../README.md): cadastro e pesquisa de indicadores, registro de cotações e gráfico de evolução.

## ▶️ Como rodar

Com o backend já rodando em `http://localhost:8080`:

```bash
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.

## 📜 Scripts

| Comando | O que faz |
|---|---|
| `npm start` | Sobe o servidor de desenvolvimento |
| `npm test` | Roda os testes |
| `npm run build` | Gera a versão de produção em `build/` |

O código principal fica em `src/App.js`.
